# 식비를 줄여라

> 냉장고 속 재료로 오늘 한 끼, 자신 있게.

냉장고 재료를 넣으면 **레시피 창고**에서 지금 만들 수 있는 요리를 찾아 주는 웹앱입니다. 창고에는 앱에 들어 있는 기본 레시피 100개와 모두가 함께 쌓은 레시피가 있습니다. **내 제미나이(Gemini) API 키**를 연결하면 AI가 내 재료에 맞춘 새 요리를 더 찾아 주고, 유튜브 요리 영상을 레시피로 정리해 줍니다.

- 사이트: https://eastflame28-bit.github.io/sikbi-julyeora/

![식비를 줄여라](public/assets/og.png)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 재료 입력 | 입력칸 하나에 쉼표나 Enter로 넣기. 자주 쓰는 재료 추천, 기본 양념은 접어서 한 번에 고르기 |
| 요리 찾기 | 지금 만들 수 있는 요리 / 재료 1~2개만 더 있으면 되는 요리로 나눠 보여 줌. 여러 사람이 만든 요리가 먼저 |
| AI로 더 찾기 | 제미나이가 내 재료와 "맛있더라" 메모를 보고 새 요리 3개를 전체 조리 순서까지 작성 |
| 모두의 레시피 창고 | 로그인한 사람이 AI로 찾은 레시피가 공용 창고에 쌓여 다음 사람은 AI 없이 바로 받음 |
| 유튜브 | 레시피마다 유튜브 검색 바로가기. 영상 링크를 넣으면 AI가 레시피로 정리 (내 레시피에만 저장) |
| 레시피 보기 | 있는 재료/없는 재료, 대체 재료, 단계별 불 세기·시간·완료 기준·흔한 실수 |
| 대체 재료 | 없는 재료를 집에 있는 재료로 대신할 수 있으면 '부족'으로 세지 않고 비율을 알려 줌 (맛술→소주+설탕 등 40여 가지 사전) |
| 요리 모드 | 한 단계씩 크게 보기, 단계별 타이머, 키보드 ← → 이동 |
| 내 레시피 | 즐겨찾기, "이렇게 했더니 맛있더라" 메모, 영상에서 정리한 레시피, 이번 달 예상 절약액 |
| 키보드 조작 | `1`~`3` 메뉴 이동, `/` 재료 입력, `Esc` 뒤로·닫기 |
| 반응형 · 다크 모드 | 휴대폰은 하단 메뉴, 컴퓨터는 왼쪽 메뉴와 2열 레시피 화면 |

## 동작 방식

```
① 데이터:  브라우저 ──▶ Supabase   (구글 로그인, 개인 데이터, 공용 레시피 창고)
② AI:     브라우저 ──▶ 제미나이   (각자 자기 API 키, 브라우저에만 보관)
③ 영상:   브라우저 ──▶ 유튜브 검색 (새 창)
```

- 서버 코드가 없습니다. GitHub Pages에 `public/` 폴더만 올리면 됩니다.
- Supabase 설정 전에는 데이터가 브라우저(localStorage)에만 저장되고, 기본 레시피 100개 안에서 찾습니다.
- 보안 규칙(RLS)은 `supabase/schema.sql`에 있습니다.
  - 개인 데이터는 주인만 읽고 쓸 수 있습니다.
  - 공용 창고는 누구나 읽을 수 있지만, 구글로 로그인한 사람만 추가할 수 있습니다.
  - 누가 레시피를 만들었는지는 저장하지 않습니다.
- 설정 순서는 [설정안내.md](설정안내.md)를 보세요.

## 폴더 구조

```
public/                 웹앱 (빌드 과정 없이 그대로 배포)
  index.html
  styles.css            디자인 토큰(색·간격)과 화면 스타일
  js/app.js             화면과 동작
  js/store.js           저장소 (Supabase / localStorage)와 구글 로그인
  js/pool.js            레시피 창고 검색·공유·반응 수
  js/gemini.js          제미나이 연결, AI 추천, 영상 정리
  js/subs.js            대체 재료 사전 (없을 때 대신 쓰는 재료와 비율)
  js/catalog.js         재료 이름, 이름 맞추기 규칙(진간장=양조간장 등)
  js/seed-recipes.js    기본 레시피 100개
  js/config.js          Supabase 설정
  assets/               로고, 일러스트
supabase/schema.sql     데이터베이스 표와 보안 규칙
```

## 로컬에서 실행

빌드 도구가 없어서 아무 정적 파일 서버로 `public/` 폴더를 열면 됩니다.

```bash
npx serve public
```

## 배포

- `main` 브랜치에 올리면 GitHub Actions가 `public/` 폴더를 GitHub Pages로 배포합니다.
- GitHub Pages는 상업용 서비스 운영 용도로는 쓰지 않도록 안내하고 있습니다. 유료 서비스로 운영할 때는 다른 호스팅(예: Cloudflare Pages, Vercel)으로 옮기세요.
