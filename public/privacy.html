개인정보처리방침

시행일: 2026년 11월 4일

「식비를 줄여라」(이하 "서비스")는 냉장고 재료로 만들 수 있는 요리를 찾아 주는 웹앱입니다. 서비스는 꼭 필요한 정보만 받고, 광고나 판매 목적으로 쓰지 않습니다.

1. 받는 정보

언제무엇을어디에 저장
Google로 로그인할 때이름, 이메일 주소, 프로필 사진 주소, 계정 고유 번호Supabase (서비스 데이터베이스)
로그인하고 앱을 쓸 때입력한 재료, 설정(인분, 빼고 싶은 재료, 외식 금액, 화면 테마), 즐겨찾기, "이렇게 했더니 맛있더라" 메모, 요리 완료 기록, 영상에서 정리한 레시피Supabase
로그인하지 않고 쓸 때위와 같은 앱 데이터사용자 기기의 브라우저에만 저장 (서비스로 보내지 않음)
제미나이 API 키를 연결할 때사용자가 넣은 API 키사용자 기기의 브라우저에만 저장 (서비스로 보내지 않음)

서비스는 쿠키를 이용한 광고, 방문 분석 도구를 쓰지 않습니다.

2. 쓰는 목적

  • 로그인하고, 여러 기기에서 같은 데이터를 보여 주기 위해
  • 내 재료에 맞는 요리를 찾고, 즐겨찾기·메모·요리 기록을 보관하기 위해

3. 모두의 레시피 창고

  • 로그인한 사용자가 AI로 새 레시피를 찾으면, 레시피 원본(요리 이름, 재료, 조리 순서)이 모든 사용자가 볼 수 있는 공용 창고에 저장됩니다.
  • 이때 누가 만들었는지는 저장하지 않습니다. 메모, 재료 목록 같은 개인 데이터는 공유되지 않습니다.
  • "만들었어요"·즐겨찾기를 누르면 레시피별 숫자만 다른 사용자에게 보입니다. 누가 눌렀는지는 보이지 않습니다.

5. 보관 기간과 지우기

  • 정보는 사용자가 지우거나 탈퇴를 요청할 때까지 보관합니다.
  • 앱의 설정 → 내 데이터 모두 지우기로 재료, 즐겨찾기, 메모, 요리 기록을 바로 지울 수 있습니다.
  • 설정 → 내 데이터 내려받기로 내 데이터를 파일로 받을 수 있습니다.
  • 로그인 계정(이름, 이메일)까지 지우려면 아래 문의처로 "계정 삭제 요청"을 남겨 주세요. 확인 후 지웁니다.
  • 공용 창고의 레시피 원본에는 개인정보가 없어서 계정을 지워도 남습니다.
  • 제미나이 키는 앱 오른쪽 위 AI 설정 → 연결 끊기로 지울 수 있습니다.
